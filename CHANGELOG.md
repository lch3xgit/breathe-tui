## [0.1.0] - 2026-09-22

### Added

- Six built-in breathing practices: Coherence, Calm, Upshift, Box Breath, Circular Flow, and 4-7-8.
- Responsive alternate-screen terminal interface with a persistent wordmark and shaded breath meter.
- Pause and resume controls that exclude paused time from the active session.
- Optional terminal-bell cues at live phase changes.
- Clean terminal restoration and line-oriented non-TTY fallback.
- Deterministic tests for practice, timing, rendering, input, sound, and terminal lifecycle behavior.
- Release automation for Windows AMD64, macOS ARM64 and AMD64, and Linux ARM64 and AMD64 archives with SHA-256 checksums.
